# Python e IA no SENAI

Projetos do curso de Inteligência Artificial com Python do SENAI: fundamentos, análise de dados, machine learning e visão computacional.

## Projeto principal: previsão de atraso de voos

[`flight-delay-prediction-xgboost/`](./flight-delay-prediction-xgboost) traz o fluxo completo de um classificador: pré-processamento com Label Encoding, treino com XGBoost, modelo salvo em arquivo e previsão para um voo ou para um lote.

| Métrica | Resultado |
|---|---|
| Acurácia | 91,67% |
| F1-Score | 91,72% |
| ROC-AUC | 97,14% |
